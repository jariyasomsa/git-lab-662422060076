# เว็บเพจแนะนำตัว

ใบงานปฏิบัติการ Git พื้นฐาน

## ผู้จัดทำ
- นางสาวจริยา สมสา รหัสนักศึกษา 662422060076
- สาขาวิชา (กรอกสาขาวิชาของคุณ)

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|------|---------|
| index.html | หน้าแรกและส่วนแนะนำตัว |
| about.html | หน้าประวัติส่วนตัว |
| css/style.css | รูปแบบการแสดงผล |
| js/script.js | สคริปต์สลับและจดจำธีม |
| .gitignore | กำหนดไฟล์ที่ไม่ต้องติดตาม |

## วิธีเปิดใช้งาน
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

## รายการ branch
| branch | หน้าที่ |
|--------|--------|
| main | สายหลัก |
| feature/header | ส่วนหัวของหน้าเว็บ |
| feature/about | หน้าประวัติส่วนตัว |
| feature/style | CSS และ .gitignore |
| feature/script | สคริปต์สลับธีม |
| docs/readme | เอกสารประกอบ |
| experiment/merge-conflict | ทดลองแก้ merge conflict |
